# SaaS Sales Performance Analysis

## Project Overview
This project analyzes SaaS sales data to evaluate business performance, identify sales trends, and generate insights into profitability, customer segments, products, and regional performance.

## Objectives
- Analyze total sales and profit.
- Evaluate sales performance across regions and countries.
- Compare customer segments and industries.
- Identify top-performing products.
- Analyze discounts, quantities, and profitability.
- Support data-driven business decisions.

## Dataset
The dataset contains sales transaction information, including:
- Order ID and Order Date
- Country, City, Region, and Subregion
- Customer Name and Customer ID
- Industry and Customer Segment
- Product and License
- Sales, Quantity, Discount, and Profit

## Tools & Technologies
- Microsoft Excel
- Power Query
- Power Pivot
- Pivot Tables
- Data Visualization

## Key Analysis Areas
- Sales and Profitability Analysis
- Regional Performance Analysis
- Customer Segmentation
- Product Performance
- Discount Analysis
- Sales Trend Analysis

## Project Workflow
1. Data inspection and preparation.
2. Data cleaning and transformation using Power Query.
3. Data analysis using Pivot Tables and Power Pivot.
4. KPI development and performance analysis.
5. Dashboard creation and visualization.
6. Business insights and recommendations.

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Quantity Sold
- Average Discount
- Profit Margin

## Business Value
This project demonstrates how spreadsheet-based analytics can transform raw SaaS sales data into actionable business insights, helping stakeholders understand performance, identify opportunities, and make informed decisions.
